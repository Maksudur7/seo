🧵 META THREADS MARKETING AUTOMATION HUB - USER SETUP GUIDE

স্বাগতম! এই সফটওয়্যারটি দিয়ে আপনি যেকোনো পিসি থেকে Meta Threads-এ স্বয়ংক্রিয়ভাবে 
কীওয়ার্ড স্ক্যানিং, Gemini AI দিয়ে কমেন্ট পোস্টিং এবং টেলিগ্রাম অ্যালার্ট চালাতে পারবেন।

--------------------------------------------------------------------
📌 নতুন যেকোনো পিসিতে সফটওয়্যারটি সেটআপ করার নিয়ম:
--------------------------------------------------------------------

ধাপ ১: Python ইনস্টল করা (যদি পিসিতে Python না থাকে)
- https://www.python.org/downloads/ এ যান এবং Python 3.12 ডাউনলোড করুন।
- ইনস্টল করার সময় অবশ্যই "Add Python to PATH" বক্সে টিক (✔) চিহ্ন দিন।

ধাপ ২: সফটওয়্যার চালু করা (১-ক্লিক)
- ফোল্ডারে থাকা "Install_And_Start.bat" ফাইলে ডাবল-ক্লিক (Double-click) করুন।
- ফাইলটি স্বয়ংক্রিয়ভাবে সমস্ত ডিপেন্ডেন্সি ও ব্রাউজার ইন্সটল করে সফটওয়্যার উইন্ডোটি চালু করে দেবে।

ধাপ ৩: কাস্টম ক্রেডেনশিয়াল (Credentials) সেট করা
- সফটওয়্যার ড্যাশবোর্ড খুললে "Configuration & Credentials" ফর্মে যান:
  ১. Gemini API Key: আপনার API Key দিন।
  ২. Target Marketing Website URL: আপনার ওয়েবসাইটের লিঙ্ক দিন (যেমন: https://yourwebsite.com)।
  ৩. Target Keywords: আপনার কীওয়ার্ডগুলো কমা দিয়ে লিখুন (যেমন: convert pdf, pdf editor, file converter)।
  ৪. Telegram Bot Token & Chat ID: আপনার টেলিগ্রাম বটের তথ্য দিন।
- নিচে "Save Configuration" বাটনে চাপ দিন।

ধাপ ৪: Threads অ্যাকাউন্ট লগইন করা
- "Browser Login Manager" সেকশনে গিয়ে "Login Threads (PC Chrome)" নীল বাটনে চাপুন।
- স্ক্রিনে Chrome খুললে Threads অ্যাকাউন্টে লগইন করে ব্রাউজার বন্ধ করুন।
- স্ট্যাটাস "✅ Logged In" হয়ে যাবে।

ধাপ ৫: অটোমেশন স্টার্ট দেওয়া
- "Start 24/7 Automation" বাটনে চাপুন।
- সফটওয়্যার বন্ধ করে দিলেও এটি পিসির টাস্কবারে (ঘড়ির পাশে) নীরবভাবে ২৪/৭ অটোমেশন রানিং রাখবে।
